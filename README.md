📝 To-Do List App

A simple and clean Flutter To-Do List App built for the Laravel Developer Recruitment Test.
This app allows users to sign up, log in, add tasks, edit tasks, mark them as complete/incomplete, and delete tasks.
It also integrates Firebase Authentication and uses Provider / BLoC / Riverpod (depending on your code) for state management.

🚀 Features
Authentication

🔐 Signup & Login using Firebase Authentication

🔓 Secure authentication with email & password

🚪 Logout functionality with confirmation dialog

Task Management

➕ Add new tasks (Title & Description)

✏️ Edit existing tasks

✅ Mark tasks as Complete/Incomplete

❌ Delete tasks

✍️ Completed tasks displayed with strikethrough & dimmed color

UI / UX

🎨 Clean & responsive Flutter UI

🗂 Tasks displayed using ListView

📱 Works on both Android & iOS

State Management

Uses Provider for managing tasks efficiently
